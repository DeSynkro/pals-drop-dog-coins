# Changelog

All notable changes to Pals Drop Dog Coins are recorded here.

This is an updated version of [Pals Drop Dog Coins](https://steamcommunity.com/sharedfiles/filedetails/?id=3626214974)
by **KoZ**. His original mod is still available and still works on its own. Thank you
to him for the base work.

## [1.1] - 2026-10-10

Comments only. No drop rates, items or quantities changed, so nothing about how the
mod plays is different from 1.0.

- Added a display name above every row, including KoZ's original ones, so you can
  look up any Pal in the files without cross referencing internal IDs.
- All 644 rows are now labelled. Names come from the game's own Pal data.

## [1.0] - 2026-10-10

First release. KoZ's mod updated for Palworld 1.0.

- Added the 75 Pals that arrived with Palworld 1.0. They did not drop Dog Coins
  before because the original mod predates them.
- 75 normal Pals, 74 Alpha Pals and 7 Predator Pals added, 156 rows in total.
- KoZ's 488 existing rows are carried over unchanged.
- 644 rows in total across normal, Alpha and Predator Pals.
- Same drop behaviour as the original: normal Pals drop Dog Coins at a rate of 20,
  Alpha and Predator Pals at 100. Amount is 1 to 3.
